# ADR-001: Vue 3 e TypeScript

## Estado
Aceite.

## Decisão
Usar Vue 3, TypeScript, Vite, Vue Router e o SDK oficial PocketBase.

## Consequências
- componentes claros e isolados;
- contratos de dados verificados;
- regras de negócio separadas da camada visual;
- build estático compatível com `pb_public`;
- dependências limitadas e auditadas.
