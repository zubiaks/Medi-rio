# Suporte

## Onde pedir ajuda

- **Bug reproduzível:** abre uma Issue usando o formulário de bug.
- **Nova funcionalidade:** usa o formulário de proposta.
- **Dúvida de utilização:** usa GitHub Discussions quando estiver ativo, ou uma Issue com label `question`.
- **Vulnerabilidade:** segue `SECURITY.md`; não abras uma Issue pública.

## Informação necessária

Inclui sempre que aplicável:

- versão do Mediário ou commit;
- Windows, macOS ou Linux;
- versão de Node.js, npm e PocketBase;
- rota afetada;
- passos para reproduzir;
- comportamento esperado e observado;
- resposta HTTP do PocketBase;
- capturas sem dados pessoais;
- resultado de `npm run type-check` e `npm run build`.

## Fora de âmbito

Não é garantido suporte para:

- forks com alterações não descritas;
- versões antigas e não suportadas;
- bases alteradas manualmente;
- providers que bloqueiem o acesso ou mudem APIs externas;
- extensões do navegador que injetem erros nas páginas;
- instalações expostas à Internet sem configuração de segurança.
