# Relações e imagens do catálogo

- Relações usam checkboxes, pesquisa e chips.
- Imagens aceitam ficheiro local ou URL HTTP/HTTPS.
- Ficheiro local tem prioridade sobre URL.
- Poster: máximo 1200×1800, WebP 0,85.
- Backdrop: máximo 1920×1080, WebP 0,85.
- Logo: máximo 1600×600; PNG preserva transparência.
