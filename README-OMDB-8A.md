# OMDb 0.8.0 — Fase 8A

## Configuração

Criar em `app_settings`:

- `chave`: `omdb_api_key`
- `valor`: chave OMDb como string JSON

A chave é lida apenas pelo hook PocketBase.

## Funcionalidade

- pesquisa por título;
- filtro por tipo e ano;
- detalhe por IMDb ID;
- ratings IMDb, Metascore e votos;
- pré-visualização do payload Mediário;
- nenhuma escrita em títulos nesta fase.
