# Checklist de aceitação VOD

- [ ] Listagem abre sem HTTP 400/404.
- [ ] Criação funciona.
- [ ] Edição funciona sem mensagem persistente desnecessária.
- [ ] Qualidade guarda `fhd`, `4k`, etc. em minúsculas.
- [ ] Duplicado apresenta aviso.
- [ ] Filtros combinados funcionam.
- [ ] Oferta desativada aparece no filtro Inativas.
- [ ] Reativação funciona.
- [ ] Oferta expirada é identificada.
- [ ] Secção Onde ver aparece no detalhe do título.
- [ ] Abrir provider funciona em nova aba.
- [ ] Eliminação exige o nome exato do provider.
- [ ] `npm audit` aprovado.
- [ ] `npm run type-check` aprovado.
- [ ] `npm run build` aprovado.
- [ ] Consola sem erros gerados pela aplicação.
