# Fase 9.0 — Pesquisa e descoberta

A pesquisa global fica acessível em `Providers > Pesquisa global`.

Pesquisa localmente no PocketBase e não faz pedidos ao TMDB ou OMDb. Não requer novas chaves, hooks ou migrações.

A entrega integra a pesquisa na página Providers porque o ZIP acumulado não contém o router completo do projeto. Uma vista dedicada pode ser criada depois sem alterar o serviço de domínio.
