# ZIP 13B — notificações e acabamento da experiência

Inclui um centro de notificações no shell autenticado.

Fontes agregadas:

- alterações não lidas em listas inteligentes;
- tarefas `sync_jobs` falhadas ou parciais para admin e editor;
- providers sem credencial ou desativados para admin.

As notificações podem ser abertas, atualizadas e marcadas como lidas. O estado lido é local ao browser e limitado aos 200 IDs mais recentes.

A página inicial mantém os acessos por função e recebe uma base versionada para guardar a ordem dos blocos numa evolução seguinte.
