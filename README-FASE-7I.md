# Instalação da Fase 7I

1. Extrair sobre `D:\Mediário`.
2. Executar `LIMPAR-CSS-ANTIGO.ps1` se ainda existirem ficheiros faseados.
3. Executar `VALIDAR-FASE-7.ps1`.
4. Realizar a checklist em `VALIDACAO\FASE-7I-CHECKLIST.md`.
5. Só criar o commit depois da validação local completa.

A entrega não inclui `package.json`, `node_modules` ou o projeto inteiro, por isso a suite e o build devem ser executados na instalação real.
