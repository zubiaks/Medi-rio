# Fase 10.2 — Dashboard, diferenças e atualização em lote

## Dashboard

O botão `Listas` abre agora um dashboard com:

- total de listas;
- listas manuais e inteligentes;
- listas fixadas;
- total de itens e itens únicos;
- prateleira das listas fixadas;
- pesquisa por nome, descrição ou itens;
- filtros por tipo;
- cartões com última atualização;
- duplicação;
- abertura direta da lista selecionada.

## Atualização em lote

A ação `Atualizar inteligentes` executa sequencialmente todas as listas inteligentes. É possível pedir cancelamento entre listas. Uma falha não impede a atualização das restantes.

## Diferenças

A pré-visualização de uma lista inteligente passa a indicar quantos resultados são novos, removidos e inalterados em relação ao snapshot materializado.

## Pesquisa interna

Cada lista permite pesquisar localmente pelo título, subtítulo ou entidade dos itens.
