# Fase 9.1 — detalhes contextuais

A seleção de um resultado já não fecha imediatamente a pesquisa. Abre um detalhe contextual com factos, relações e dados técnicos.

Para títulos, são carregadas fontes externas, aliases, temporadas e créditos. Para pessoas, são carregados créditos com expansão de título e função.

A ação `Usar na página atual` mantém o comportamento anterior de transferir o nome para o filtro de Providers.
