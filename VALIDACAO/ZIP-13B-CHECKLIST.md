# ZIP 13B — checklist

- [ ] Centro de notificações aparece no shell autenticado.
- [ ] Leitor não recebe tarefas nem providers.
- [ ] Utilizador recebe alterações das listas.
- [ ] Editor recebe listas e tarefas falhadas/parciais.
- [ ] Admin recebe listas, tarefas e providers por configurar.
- [ ] Selecionar uma notificação abre a rota correta.
- [ ] Marcar todas como lidas atualiza o contador.
- [ ] Atualizar volta a consultar as fontes autorizadas.
- [ ] Falha numa fonte não elimina notificações das restantes.
- [ ] Login e recuperação continuam sem shell privado.
