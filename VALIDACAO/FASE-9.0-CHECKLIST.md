# Fase 9.0 — Pesquisa e descoberta

- [ ] O botão Pesquisa global abre o diálogo.
- [ ] Pesquisa títulos por título, título original e sinopse.
- [ ] Pesquisa pessoas por nome, aliases e biografia.
- [ ] Pesquisa coleções, episódios, streams, títulos alternativos e fontes.
- [ ] Os filtros de entidades funcionam independentemente.
- [ ] O filtro de ano limita apenas títulos.
- [ ] O filtro de provider limita fontes externas.
- [ ] Títulos apagados ficam excluídos por omissão.
- [ ] Grelha e lista são legíveis em desktop e móvel.
- [ ] O histórico é deduplicado e limitado a 12 termos.
- [ ] Limpar histórico remove apenas dados locais de pesquisa.
- [ ] Nenhuma pesquisa envia dados para providers externos.
- [ ] Os pedidos anteriores são substituídos através de requestKey por entidade.
