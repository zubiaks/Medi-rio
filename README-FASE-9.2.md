# Fase 9.2 — descoberta, pesquisas guardadas e comparação

Inclui dois modos no diálogo global:

- Pesquisar: pesquisa transversal, filtros, predefinições e comparação.
- Descobrir: prateleiras criadas exclusivamente a partir do catálogo local.

As pesquisas guardadas e a comparação permanecem no browser. A descoberta não consulta providers externos.
